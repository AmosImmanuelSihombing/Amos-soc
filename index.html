01. Sistem Deteksi & Pencegahan Serangan DDoS Berbasis Threshold

Tugas Akhir Sarjana Komputer • Universitas Pembangunan Jaya (2026) • Dosen Pembimbing: Prio Handoko, S.Kom., M.T.I.

Automated Real-Time DDoS Detection & iptables Mitigation Engine

VPS Ubuntu Server Domain Publik: ddosta.my.id Nginx Web Server
✓ COMPLETED THESIS

Membangun sistem perlindungan web server independen yang memantau lonjakan trafik HTTP secara real-time dari log akses Nginx. Saat trafik melampaui ambang batas keamanan (threshold breach), sistem secara otomatis menginjeksi aturan pemblokiran pada firewall Linux iptables tanpa downtime bagi pengguna sah lainnya.

TAHAP 1

Telemetri Real-Time Efisien via seek(0,2)

Program Python monitor.py membuka access.log Nginx langsung dari baris terakhir tanpa membaca ulang berkas dari awal, meminimalkan beban CPU & memori server.

TAHAP 2

Sliding Window Request Counter (10 Detik)

Mengelompokkan kedatangan request per source IP menggunakan deque. Jika suatu IP melebihi 1000 request dalam interval 10 detik, sistem langsung mencatatnya ke attack.log.

TAHAP 3

Injeksi Aturan Isolasi Firewall iptables

Mengeksekusi perintah iptables -A INPUT -s <IP> -j DROP seketika. Paket dari penyerang langsung dibuang di level kernel Netfilter sebelum mencapai web server.

TAHAP 4

Mekanisme Auto-Release Timer (300 Detik)

Menghindari pemblokiran permanen terhadap pengguna sah (mitigasi False Positive). Background timer otomatis menjalankan iptables -D dan mencatat ke unblocked.log.

Cuplikan arsitektur pemantauan log real-time pada monitor.py:

# Membaca log Nginx secara real-time dari EOF with open("/var/log/nginx/access.log", "r") as f: f.seek(0, 2) # Langsung ke ujung baris terbaru while True: line = f.readline() if not line: time.sleep(0.1) continue ip = line.split()[0] now = time.time() requests[ip].append(now) # Evaluasi sliding window 10 detik while requests[ip] and now - requests[ip][0] > WINDOW: requests[ip].popleft() if len(requests[ip]) > THRESHOLD and ip not in blocked_ips: block_ip(ip)

Otomasi Netfilter Chain INPUT dan timer pelepasan otomatis:

def block_ip(ip): # Tambahkan rule DROP pada chain INPUT subprocess.run(["iptables", "-A", "INPUT", "-s", ip, "-j", "DROP"], check=True) blocked_ips.add(ip) log_file("blocked.log", f"BLOCKED | {ip}") # Jalankan background timer 300 detik untuk auto-release timer = threading.Timer(300, unblock_ip, args=[ip]) timer.start()

Ketersediaan Layanan Web Tetap 100% Online

Pengujian pada domain publik ddosta.my.id membuktikan bahwa saat penyerang diblokir seketika oleh iptables, pengguna lain dapat tetap mengakses website dengan respons HTTP 200 normal tanpa lonjakan latency.
