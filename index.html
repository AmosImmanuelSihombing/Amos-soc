01. Tugas Akhir Sarjana • Sistem Deteksi & Mitigasi DDoS

Sistem Deteksi dan Pencegahan Serangan DDoS Berbasis Threshold pada Web

Universitas Pembangunan Jaya • 2026 • Pembimbing: Prio Handoko, S.Kom., M.T.I.
✓ COMPLETED THESIS

Merancang dan mengimplementasikan sistem pendeteksi lonjakan trafik DDoS secara mandiri yang berjalan pada server publik (Virtual Private Server). Sistem memantau dan menganalisis berkas catatan akses secara real-time, lalu mengeksekusi mitigasi pemblokiran firewall secara otomatis tanpa intervensi manual guna menjaga ketersediaan layanan web (availability).

[1]
Telemetri Log Real-Time: Program Python monitor.py memantau berkas access.log Nginx secara langsung menggunakan mekanisme seek(0,2) untuk memproses setiap request baru secara efisien.
[2]
Analitik Deteksi Threshold: Menghitung frekuensi request dari setiap alamat IP dalam interval waktu 10 detik (sliding window). Jika melampaui batas ambang (threshold), dicatat ke attack.log.
[3]
Pencegahan Otomatis (Firewall Netfilter): Sistem mengeksekusi aturan iptables -A INPUT -s <IP> -j DROP seketika untuk mengisolasi penyerang dan mencatat ke blocked.log.
[4]
Mekanisme Pelepasan (Auto-Release): Timer background (300 detik) otomatis menghapus aturan blokir (iptables -D) guna mencegah pemblokiran permanen pengguna sah (*False Positive mitigation*).
[5]
Dashboard Monitoring Web: Dibangun dengan PHP untuk menyajikan metrik System Status, jumlah serangan, daftar IP terblokir, dan log trafik terkini secara real-time.
Python (monitor.py) Nginx Web Server Linux iptables Ubuntu VPS Real-Time Dashboard (PHP) Domain ddosta.my.id MITRE T1498 / T1499

03. Proyek Sedang Berjalan (On-Going Homelab)

Enterprise Active Directory & Security Auditing Homelab

Oracle VirtualBox • Windows Server 2022 • Windows Client
⏳ ON-GOING / IN PROGRESS

Membangun lab infrastruktur domain enterprise mandiri menggunakan Windows Server 2022 (Domain Controller corp.local) dan klien Windows di VirtualBox. Proyek difokuskan pada perancangan hierarki Organizational Units (OU), pengetatan Group Policy Objects (GPO), mitigasi serangan brute-force, serta audit Windows Security Event Logs.

[Progress 1]
Hierarki Organisasi (OU) & RBAC: Merancang pemisahan OU per departemen (Finance, IT Support, Workstations) dan menerapkan prinsip hak akses minimal (Least Privilege).
[Progress 2]
GPO Security Hardening: Mengonfigurasi Account Lockout Policy (5x percobaan gagal), Password Complexity minimal 12 karakter, dan mematikan protokol rentan SMBv1.
[Progress 3]
Security Event Auditing (SOC Triage): Mengaktifkan audit logging untuk menganalisis Event ID 4624 (Logon Sukses), Event ID 4625 (Logon Gagal), dan Event ID 4740 (Account Lockout).
Active Directory (AD DS) Windows Server 2022 Group Policy (GPO) Event ID 4625 / 4740 Oracle VirtualBox MITRE T1110.001
